# RouteLocation v1.2.23 Implementation Plan

> **For agentic workers:** Execute this plan inline, task by task. Keep each task's test cycle and commit separate. The approved v1.2.23 prompt in the current conversation is the governing spec.

**Goal:** Make frequent map, route-library, paste, and tutorial interactions more predictable while adding a strictly optional viewport-only S2 grid.

**Architecture:** Keep simulation and route playback services unchanged. Add UI-facing state helpers around existing selection/focus, saved-route persistence, and tutorial layout. Implement S2 as an isolated pure-Swift geometry/viewport controller that emits only MapKit overlay values; the simulation model never imports or references it.

**Tech Stack:** Existing SwiftUI/MapKit app, `RouteLocationModel`, `RoutePersistenceStore`, `PlaceInfoResolver`, XCTest/Swift Testing, GitHub Actions build and guide-capture workflows. No new third-party dependency unless the isolated implementation proves infeasible and is re-reviewed.

**Spec:** User-approved v1.2.23 requirements in the conversation; no external spec file.

## Global Constraints

- Base SHA is `bed5c4b3d189a24963d358f27d08b86737bc6e30`; work only on `feat/v1.2.23-everyday-s2-polish`.
- Keep single-point map taps as selection; keep Route-mode map taps as immediate waypoint additions.
- Map taps preserve camera zoom; only intentional navigation recenters.
- Saved-route preview never mutates the editable draft; multi-point paste with a draft requires Replace / Append / Cancel.
- Imported routes persist as SavedRoute before UI publication and use local straight geometry; never replace the map draft.
- S2 defaults OFF, is isolated from all location/playback services, limits work to viewport plus buffer, caps cells, and drops stale calculations.
- Tutorial coach content must not overlap protected target touch frames; retain Skip, interruption, and production-state completion behavior.
- Do not modify LocalDevVPN, RemotePairing, RSD, DVT, cellular bootstrap, FFI, simulation core, or route playback architecture.
