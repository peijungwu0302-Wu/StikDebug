## Binding boundaries

Tutorials observe existing production state and never own simulation, persistence,
playback clocks, connection recovery, or cellular control. User actions alone
invoke production simulation/start/restore controls. Skip removes guidance only.
No credentials, private fixture data, telemetry, network service, or new protocol.

## Design rulings

- Active tutorials use the existing standard Map view without changing the saved
  Classic/V2 preference. Ending guidance restores the preferred presentation;
  simulation lives in the model and continues unchanged.
- Missing/off-screen targets leave the app operable with a reachable exit and
  contextual instructions. Production alerts retain priority. Backgrounding
  suspends guidance; foreground success is evaluated from actual state.
- Optional Taipei 101 demo-fill changes only input text when explicitly tapped.
  Preview and simulation still require their existing production buttons.
- Keep animation minimal. No external coach-mark dependency.
